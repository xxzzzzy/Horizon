### [GitHub Copilot 应用重构巨型 PR 渲染管线](https://github.blog/engineering/user-experience/rendering-huge-pull-requests-in-the-github-copilot-app/) ⭐️ 8.0/10

GitHub 工程团队在 Copilot 应用中重建了拉取请求视图，使其能够流畅渲染包含 2200 余个文件、超过 100 万行变更以及 400 多条内联评审评论的巨型开源 PR。团队为纯代码行保留了 &quot;渲染前即知全部高度&quot; 的契约，使用命令式回收式行渲染器、类型化数组几何表、由后端持有并按结构优先流式传输的 diff 文档，以及支持精确 &quot;滚动到第 N 行&quot; 的命令式滚动 API，因此每帧工作量与总行数无关。评审线程、可展开区块、回复编辑器等高度依赖运行期信息的动态元素，则被建模为按文件、行和侧锚定的 &quot;动态块&quot;，其高度测量走独立的几何索引，通过内容指纹与宽度桶缓存复用测量值，避免窗口尺寸变动导致全量失效。测量阶段摒弃了每块一个 ResizeObserver 的初版方案，改用单一、空闲与滚动门控的测量通道，候选范围限定在距视口约 2400 像素以内的块，使工作量降为 O\(视口\)，并把测量写回限制在用户当前正在查看的内容附近以避免滚动跳跃。

rss · GitHub Blog · 9月23日 18:29

**「背景」** 虚拟列表是处理大列表渲染的常用方案：通过只挂载可视区附近的行并复用 DOM 节点，配合由行高累加得出的滚动几何表，把滚动条长度、定位与跳转都转化为算术。该方案的前提是每行高度在首次绘制前可知，因此对固定字号、固定行高的代码行非常有效。但评审评论的高度取决于 markdown 换行方式、\`&lt;details&gt;\` 展开状态、内嵌回复编辑器、建议改动 diff、图片异步加载等运行期才能确定且会持续变化的因素，传统虚拟化在动态内容上会出现过度预留产生的空白、欠预留产生的内容裁切或嵌套滚动条，以及测量回写造成的滚动跳跃。

**「影响」** 在 Copilot 应用中评审包含数千文件、上百万行变更和数百条内联评论的大型 PR 的开发者，现在可在不出现明显卡顿或滚动跳跃的情况下打开并滚动该 PR。

### [Claude Code 仅在遥测开启时读取 AGENTS.md \[已修复\]](https://blog.szypowi.cz/p/claude-code-reads-agents.md-only-when-telemetry-is-on/) ⭐️ 7.0/10

Claude Code 此前存在一个隐蔽缺陷：当用户关闭遥测（telemetry）时，工具不会读取仓库中的 AGENTS.md 项目指令文件，只有在遥测开启时才会生效。该问题源于功能开关（feature flag）驱动的渐进式发布机制：发布者需要通过遥测来远程关闭该功能，因此未开启遥测的用户实际上从未进入该代码路径，从而完全跳过 AGENTS.md 的解析。Anthropic 团队成员 mpoteat 在 Hacker News 上确认这是一个发布残留（rollout artifact）导致的人为错误，并已在 v2.1.281 版本中修复。讨论还揭示了另一项非默认行为：当存在 CLAUDE.md 时，Claude Code 默认会优先读取 CLAUDE.md 而忽略 AGENTS.md，包括用户主目录下的 ~/CLAUDE.md；只有将“项目指令（Project instructions）”设置为非默认的 \`claude-md-and-agents-md\` 才会同时读取两者。

hackernews · pszypowicz · 9月23日 12:15 · [社区讨论](https://news.ycombinator.com/item?id=49814947)

**「背景」** AGENTS.md 是面向 AI 编程助手的项目级指令文件，功能上类似于 Cursor、Aider 等工具中常见的约定，用来告诉 AI 编码代理项目的构建方式、测试规范和代码风格。Claude Code 同时支持 AGENTS.md 和其自家的 CLAUDE.md，并提供“项目指令”设置来控制是否同时读取两者。许多团队依赖 AGENTS.md 来跨不同 AI 工具统一项目上下文，因此其是否被正确加载会直接影响代理行为。

**「影响」** 对于在 Claude Code 中关闭遥测并依赖 AGENTS.md 提供项目指令的开发者来说，该 bug 会导致其指令被静默忽略，代理按通用默认行为运行而非遵循仓库规范。建议升级到 v2.1.281 或更高版本，并检查是否需要将项目指令设置切换为 \`claude-md-and-agents-md\` 以避免被 CLAUDE.md 覆盖。

**「社区讨论」** 社区对此普遍感到担忧，认为这类极易被忽视却又影响严重的缺陷，正是在不断叠加 AI 生成补丁、缺乏人工审查时容易出现的典型问题。讨论中也有人指出，功能开关式的渐进式发布本身合理，但若长期将特性保留在 flag 判断之下、且与遥测耦合，就会埋下类似隐患；同时有用户补充了 CLAUDE.md 优先于 AGENTS.md 的实际经验，提醒其他开发者注意设置项。

rss · Hugging Face Blog · 9月23日 18:41

**「相关技术背景」** NVIDIA Warp 是一个用纯 Python 编写静态类型 GPU kernel 的框架，支持 SIMT 执行、JIT 编译为原生 CUDA、内置向量/矩阵/四元数/BVH 等数据结构，并可通过 DLPack 与 PyTorch、JAX 等训练框架互操作。MJWarp 是把 MuJoCo 物理管线在 Warp 上重写的实现，能够把同一 MJCF 模型与一组独立状态一起放到 GPU 上批量推进，因此天然适合作为 RL 训练中的环境并行层。
